A research-oriented implementation of **power allocation in IoT wireless networks using Graph Attention Networks (GAT)**.  
This project models IoT devices as nodes in an interference graph and learns transmit power levels that maximize the **network sum-rate**.

The implementation is provided as a **Jupyter Notebook simulation framework** that demonstrates how **Graph Neural Networks (GNNs)** can be applied to wireless resource allocation problems.

---

# Project Overview

Wireless IoT networks suffer from **interference between transmitting devices**, making optimal power allocation a challenging problem.

This project explores a **Graph Attention Network (GAT)** based solution that:

- Models wireless nodes as a **graph structure**
- Uses **attention mechanisms** to capture interference relationships
- Predicts **transmit power levels** for each node
- Maximizes the **overall network throughput (sum-rate)**

The learned policy is compared with traditional baselines such as **random allocation** and **maximum power transmission**.
